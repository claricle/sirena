= CLI Reference

Complete reference for the Sirena command-line interface.

== Getting Help

Running `sirena` without a command displays the command list. The root help
forms below do the same:

[source,shell]
----
sirena
sirena help
sirena -h
sirena --help
----

Use `help` with a command name for that command's usage and options:

[source,shell]
----
sirena help render
sirena help batch
----

The CLI also provides a command tree:

[source,shell]
----
sirena tree
----

`--help` and `-h` are root-level help forms, not command options. For example,
`sirena render --help` treats `--help` as the input file and fails if that file
does not exist. Use `sirena help render` instead.

== Commands

=== render

Render one Mermaid diagram as SVG.

[source,shell]
----
sirena render [FILE]
----

==== Argument

`FILE`::
  Optional Mermaid input file. When omitted, or when `FILE` is `-`, Sirena
  reads Mermaid source from standard input.

==== Options

`--output PATH`, `-o PATH`::
  Write SVG to `PATH`. Without this option, SVG is written to standard output.

`--format FORMAT`, `-f FORMAT`::
  Output format. Defaults to `svg`; SVG is the only supported format.

`--theme THEME`, `-t THEME`::
  A built-in theme identifier or a path to a theme YAML file. Built-in themes
  are `default`, `dark`, `light`, and `high_contrast`.

`--verbose`, `-v`::
  Enable verbose output. It defaults to false. On an error, verbose mode also
  prints the backtrace.

==== Examples

Render a file to an SVG file:

[source,shell]
----
sirena render diagram.mmd -o diagram.svg
----

Render standard input, with either supported stdin form:

[source,shell]
----
cat diagram.mmd | sirena render
cat diagram.mmd | sirena render -
----

Select SVG explicitly and use a built-in theme:

[source,shell]
----
sirena render diagram.mmd -f svg -t dark -o diagram.svg
sirena render diagram.mmd -t high_contrast -o diagram.svg
----

=== batch

Render Mermaid files in a directory.

[source,shell]
----
sirena batch [OPTIONS]
----

`batch` has no positional argument; use `--input` or `-i` to choose input.

==== Options

`--input PATH`, `-i PATH`::
  Input directory or file. Defaults to the current directory (`.`).

`--output PATH`, `-o PATH`::
  Output directory. Defaults to `output`.

`--theme THEME`, `-t THEME`::
  A built-in theme identifier or a path to a theme YAML file. There is no
  explicit option default.

`--verbose`, `-v`::
  Enable verbose output. It defaults to false.

When the input is a directory, Sirena recursively finds every `.mmd` file and
writes an `.svg` file under the output directory with the same relative path.

For example:

[source,shell]
----
sirena batch -i diagrams -o output
sirena batch -i diagrams -o output -t dark
----

Batch status is reported in its summary. Current edge-case behavior is:

* A nonexistent input path prints `No .mmd files found` and exits 0.
* A direct `.mmd` file input currently creates the output directory, then
  reports an `Errno::EISDIR` failure while writing to it; its summary reports
  the failure and the command exits 0.
* A file that fails to render does not stop later files. The summary records
  successes and failures, and this per-file failure path exits 0.

=== version

Show the Sirena version:

[source,shell]
----
sirena version
sirena --version
sirena -V
----

Each form prints:

----
sirena version 0.1.0
----

== Environment Variables

The CLI does not currently read any `SIRENA_*` environment variables.

== Exit Behavior

Successful commands and root help exit 0. Errors handled by `render`, such as a
missing input file or an unsupported format, print `Error: ...` and exit 1.

`batch` records individual render failures in its summary instead of aborting.
The missing-path, direct-file, and per-file-failure cases described above all
currently exit 0; check the summary rather than relying on the process status
alone for those cases.
