== Sirena Documentation

Welcome to Sirena, a pure Ruby Mermaid diagram rendering library that converts Mermaid syntax into beautiful SVG diagrams. Built for server-side rendering, Sirena provides native integration with Ruby applications without requiring Node.js or browser dependencies.

== Why Sirena?

=== Pure Ruby Implementation
* No Node.js dependencies
* No Puppeteer/Chrome requirements
* Simpler deployment in Ruby environments
* Callable directly from Rails, Jekyll, and any Ruby application (no
  dedicated integration layer built yet)

=== No Browser Dependency
* No headless browser launch required
* Suitable for serverless environments
* No committed, reproducible benchmark yet backs a specific speed or memory
  claim (see the comparison page)

=== Comprehensive Diagram Support
* 24 diagram types registered (compatibility varies by type; see the compatibility page)
* Mermaid.js syntax compatibility
* Advanced theming system
* Professional-quality SVG output

== Quick Start

[source,ruby]
----
# Installation
gem install sirena

# Basic usage
require 'sirena'

svg = Sirena.render(<<~MERMAID)
  graph TD
    Start --> End
MERMAID

puts svg
----

See link:guides/quick-start/[Getting Started Tutorial] for complete installation and usage instructions.

== Key Features

* **Theme System**: YAML-based theming with 4 built-in themes (default, dark, light, high_contrast)
* **Batch Processing**: Built-in batch renderer for documentation sets
* **Ruby Integration**: Call `Sirena.render` directly from Rails, Jekyll, or
  any Ruby application; no dedicated Rails helpers or Jekyll plugin exist yet
* **Parslet Parsing**: Robust grammar-based parsing with clear error messages
* **SVG Output**: Professional-quality scalable vector graphics
