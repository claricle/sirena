* **Batch Processing** - Multiple diagrams at once, processed sequentially

== Built-in Themes

Sirena includes four built-in themes:

* **Default** - Classic Mermaid.js-compatible styling
* **Dark** - Dark background with high contrast
* **Light** - Minimalist light theme
* **High Contrast** - Higher-contrast colors

See link:../../pages/compatibility/[Compatibility Comparison] for how Sirena's themes map to Mermaid.js's.

== Integration Features

Sirena is a plain Ruby gem: `Sirena.render` can be called from any Ruby application,
Rake task, or CI script. There is no Rails engine, Jekyll plugin, or Metanorma-specific
integration code in the gem today -- its SVG output is self-contained (no external CSS)
so it embeds cleanly wherever an app already handles SVG, including Metanorma documents.

=== Build Tool Integration

* **Rake Tasks** - `tasks/*.rake` covers example generation and corpus checks during development
* **CI/CD** - Runs anywhere a Ruby CI job can (GitHub Actions and others)

== Performance Features

* **Batch Processing** - Renders a directory of files sequentially (`sirena batch`); not parallelized

No caching layer or plugin system exists yet.

== Unique Advantages

=== vs. Mermaid.js

* **No Node.js** - Pure Ruby, no JavaScript runtime
* **No Browser** - No Puppeteer/headless Chrome
* **Native Ruby** - First-class Ruby integration

A dated Apple M2 comparison run and the commands used to reproduce it are published
in the link:../../performance-benchmark/[Performance Benchmark report]. It did not
measure memory and does not establish a machine-independent speed multiplier.

== Extensibility

Sirena is extended through `Sirena::Notation.register(plugin)`, which adds a
whole notation (see ARCHITECTURE.md, "Registry Pattern (Notation)"), and
`sirena render --require` to load such a file. Built-in diagram types are rows of
`Sirena::Notation::Mermaid::TYPES`. `Sirena::DiagramRegistry` is a read-only,
deprecated facade and has no `register` method.

* **Custom Themes** - Create your own themes (name, `Theme`, or `Hash`)
